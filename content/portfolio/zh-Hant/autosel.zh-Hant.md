# AutoSEL

AutoSEL 是一個以自動化 Docker 容器的 SELinux 政策產生與套用為主題的碩士論文專案。系統監控容器事件與設定，接著產生、更新並套用符合容器需求的安全政策。

## 工程挑戰

面對持續變動的容器工作負載，SELinux 政策管理需要檢查容器設定、產生適當規則，並在容器變更時維持控管一致。AutoSEL 探索如何將這段生命週期自動化。

## 架構與設計

- 監控 Docker 容器事件，並在工作負載啟動或變更時檢查容器設定。
- 解析容器設定，準備政策產生元件所需的輸入。
- 產生並載入 SELinux 政策，再使用客製化 SELinux Label 套用至容器。
- 當監控事件需要更新政策時，重新產生政策並替換受影響的容器。

容器政策生命週期如下：

1. Docker 事件
2. 容器檢查
3. 政策產生
4. 載入 SELinux 政策
5. 容器套用控管

## 實作內容

- 將容器監控、設定解析、政策建立與政策套用拆分為不同元件。
- 依 Docker 容器事件自動產生並重新載入政策。
- 記錄套用產生政策與 SELinux Label 時使用的容器替換流程。
- 示範特權容器、裝置掛載、主機掛載與系統能力的政策控管。

## 驗證與影響

- 專案文件包含自動產生與重新載入政策的示範，也包含對特權操作、掛載與系統能力的限制。
- 這些是專案示範結果，未宣稱正式環境部署、規模效能基準或營運影響量測。

## 限制與後續工作

- 重新套用政策可能需要停止並替換容器，因此必須評估工作負載中斷與資料處理方式。
- 現有專案紀錄未提供大規模效能結果或正式環境部署驗證。

## 工程重點

這個碩士論文專案將 Linux 安全、Docker 生命週期事件、SELinux 政策產生與容器控管整合為一套自動化流程。
